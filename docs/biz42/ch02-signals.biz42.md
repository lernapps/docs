# Chapter 2: Signals

## AI assistants make building cheap

A motivated teacher or parent can now build a working learning app in a weekend with an AI assistant. Many such apps are made for one class or one child, and stay there.

## Unsafe tools in class

Teachers who need something now use tools that want an account, show ads or send data to servers they cannot judge, often on private accounts, because checking whether a tool may be used takes longer than the lesson.

```biz42
:::signal
id: sig-unsafe-tools
title: Teachers use unchecked tools because checking takes too long
source: external
surfaces: risk-unsafe-adoption, risk-dsgvo, opp-fitness-signal
:::
```
